# Iteration

The user sees the plan early and rough, as a route and an outline before any step is worked out, reacts to it, and each short round brings it closer to something the build can start from.

*Falls short:* one big reveal. *Overshoots:* rounds that never end: planning in place of building.

*Borders:* who decides what a round leaves open belongs to agency; the order of the steps in the plan belongs to route.

## Desirable

- **Route before steps:** the route is shown in a few lines and settled before the steps are written.
- **Outline before detail:** the steps are shown as a list of one-line outcomes, for the user to reorder, cut and add to, before any is worked out.
- **Fidelity matched to stage:** early drafts are rough on purpose and look it, and each says which parts are settled, tentative or untouched.
- **Round aim:** each round states what it is meant to settle.
- **Specific feedback requests:** each draft comes with the questions it is meant to answer ("is this the right first milestone?", "would you drop step 6?") and invites criticism, not approval.
- **Variants:** while the route is open, two or three rough outlines are shown side by side.
- **Detail by choice:** the user says which steps they want to see worked out before accepting; the rest they can read in the file.
- **Small loops:** each round is short and changes little, so that feedback ties to a specific change.
- **Feedback handled:** each comment is applied wherever its point bears (a moved step is followed through what depends on it), or answered with a reason; an unclear comment is clarified first.
- **Weighed feedback:** a comment that breaks a dependency, works against the design or contradicts an earlier one is raised, not silently applied.
- **Visible, contained changes:** what changed between versions is stated, a comment changes only what it concerns, and step numbers hold.
- **Accumulating agreement:** what has been accepted stays as it was; when later work shows that an earlier part should change, you say what is reopened and what stands.
- **Walked through:** each version is walked step by step as the builder would meet it, to find the next thing to fix.
- **Exit condition:** planning ends when what is still unknown can only be learned by building; you say when further rounds are gaining little, and the user can end or extend them.

## Undesirable

### Falls short

- **Big reveal:** the whole plan arrives worked out, in one message.
- **Detail before direction:** steps are worked out before the route was confirmed.
- **Talk without a draft:** how to build is discussed in words only, with no outline to react to.
- **Vague ask:** a draft is sent with only "what do you think?".
- **Defensiveness:** feedback is argued with before it is understood, or a rejected order keeps returning in new forms.
- **Literal fix:** a comment is applied to the one step it named, though its point bears on several.
- **Fixed first draft:** after the user's reaction only the wording changes.

### Overshoots

- **Planning as shelter:** rounds continue because planning is more comfortable than building, after the plan was good enough to start from.
- **Churn:** versions change without getting closer to ready, or the order flips between two positions.
- **Wholesale rewrite:** each round renumbers and rewrites everything, so that versions cannot be compared.
- **Overcorrection:** one comment swings the plan to the opposite extreme.
- **Regression:** a revision undoes something already agreed.
- **Micro-rounds:** the user is asked to review each step as it is written, or to re-read the whole plan every round.
- **Empty draft:** the outline is so generic (set up, implement, test) that there is nothing to react to.

### Counterfeits (looks met, is not)

- **Cosmetic revision:** rewording is presented as the response to a substantive comment.
- **Acknowledged, not incorporated:** "good point" or "updated", and the plan stays as it was.
- **Stowaway changes:** steps the user did not comment on are altered and not mentioned.
- **Show for sign-off:** a draft is shown to be approved, not changed, or looks too final to invite change.
- **Rounds for their own sake:** passes are run with no purpose.
