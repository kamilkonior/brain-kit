# Learn: Coherence

The change fits the way of working it is added to: what is already there was read first, the change goes into the place and the wording of what it joins, what it repeats, replaces or contradicts is merged, changed or taken out, and the whole stays short enough to be read and followed.

*Falls short:* a rule laid on top of the others. *Overshoots:* the whole rewritten for the sake of one lesson.

*Borders:* where the change must be put so that it is met belongs to mechanism, and coherence says how it sits there; what the change costs later work belongs to worth; whether others who rely on the same files are asked belongs to containment; why a rule that was there did not act belongs to cause; who decides between two rules that pull against each other belongs to agency.

## Desirable

- **Read first:** before anything is written, what the way of working already says about the matter is read where it stands: the instruction files at each level, the skills, the checks, earlier lessons.
- **Already said:** where the lesson is already written, no second line is added; the one that is there is repaired.
- **One home:** each rule stands in one place, and other places point to it where they need it.
- **Joined, not appended:** the change goes into the section it belongs to, beside what it bears on, not at the end of the file under a date.
- **Voice of the place:** it is written in the terms, the form and the length of what it joins: a trait added to a skill reads like the traits beside it.
- **Contradiction settled:** where the change contradicts something that is there, one of the two is changed, and which one goes to the user where it is theirs to say.
- **Precedence said:** where two rules will both apply and pull apart (speed here, a check there), it is said which gives way, and when.
- **Superseded taken out:** what the change replaces is removed, not left beside it.
- **Levels agree:** what the project's instructions say is held against the user's own settings and the skills, and a clash between levels is named.
- **Same words:** the change uses the names already in use for a thing, and brings no second word for it.
- **Kinds kept apart:** facts about the project, rules for the work and agreements between the two of you stay in the places that hold each.
- **Whole reread:** after the change the file is read through once as its next reader will read it, from the start.
- **Still followable:** the whole is still short and plain enough that one reading leaves its rules in mind, and where it is not, that is said.
- **Skills as a system:** a change to a skill is held against its other goals and against the skills beside it, so that what it adds does not undo a border between them.
- **Proportion:** a line added to a file of ten is read against the ten.

## Undesirable

### Falls short

- **Appended:** the lesson is added at the bottom under "Lessons learned", the fourteenth of its kind.
- **Said twice:** the same rule now stands in two files in different words, and the two will drift apart.
- **Contradiction left:** one line says to ask before installing, and the new one says to install what is needed.
- **Old one left in:** the rule the lesson replaced still stands above it.
- **Levels clash:** the project says one thing and the user's own settings another, and nobody looked.
- **Second word:** the new line calls "staging" what the rest of the file calls "preview".
- **Written unread:** the change was added to a file of which only the last lines were opened.
- **Patchwork:** the file is a pile of single rules, in the order in which things went wrong.

### Overshoots

- **Rewritten whole:** the instruction file is reorganized from top to bottom in order to add one line.
- **Tidied unasked:** other people's rules are reworded on the way, for consistency.
- **One scheme for all:** every rule is forced into the same template, with headings for a sentence.
- **Merged to mush:** three exact rules are folded into one general one that no longer says what to do.
- **Pointer chain:** a line is added that points to a section that points to another file.

### Counterfeits (looks met, is not)

- **Fits in form:** the line matches its neighbours in wording, and contradicts one of them.
- **"Updated":** the old rule is said to be replaced, and both are in the file.
- **Consolidated:** a tidy section is made of all the lessons, and none of them stands any longer where it would be met.
- **Small diff:** one line was added, and it changes what ten others mean.
- **Read in name:** the file was searched for one word, and the rule on the matter uses another.
